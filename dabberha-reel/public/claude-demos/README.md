# تسجيلات شاشة حقيقية (اختياري)

المشاهد التوضيحية في فيلم `ClaudeFilm` تتبدّل تلقائياً بتسجيل شاشة حقيقي إذا حطيت الملف هنا بالاسم المناسب:

| الملف | المشهد |
|---|---|
| `C3.mp4` | تحليل الملفات والتفكير |
| `C4.mp4` | الـ Artifacts (أداة تفاعلية) |
| `C5.mp4` | البرمجة |
| `C7.mp4` | استخدام الكمبيوتر |

لما يكون الملف موجود، تتغيّر الشارة من «تمثيل توضيحي» إلى «تسجيل شاشة حقيقي». وبعدها تعيد الريندر.
