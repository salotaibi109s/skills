# skills

## Remotion Agent Skills

مهارات [Remotion](https://www.remotion.dev) الرسمية مسجّلة في `.claude/skills/`، ويحمّلها Claude Code تلقائيًا عند العمل داخل هذا المستودع.

- المصدر: [remotion-dev/skills](https://github.com/remotion-dev/skills) (commit `3e20ac7`، الإصدار 4.0.544)
- نقطة البداية: `/remotion-best-practices` (يوجّه إلى بقية المهارات)

| المهارة | الاستخدام |
| --- | --- |
| `/remotion-best-practices` | الموجّه العام لكل مهارات Remotion |
| `/remotion-create` | إنشاء مشروع أو مقطع (composition) جديد |
| `/remotion-markup` | كتابة React markup: الحركة، الخطوط، الوسائط، المؤثرات، النص العربي |
| `/remotion-studio` | تشغيل Studio لمعاينة الفيديو |
| `/remotion-render` | تصدير فيديو أو صورة ثابتة |
| `/remotion-maps` | حركات الخرائط (Mapbox، MapLibre، MapTiler، CesiumJS) |
| `/remotion-captions` | الترجمة والتعليقات النصية |
| `/remotion-saas` | بناء تطبيقات تعتمد على Remotion |
| `/remotion-interactivity` | جعل العناصر قابلة للتعديل في Studio |
| `/remotion-docs` | البحث في توثيق Remotion |
| `/remotion-license` | معلومات الترخيص |
| `/remotion-upgrade` | ترقية Remotion والحزم المرتبطة |
| `/remotion-multimedia` | التعامل مع الصوت والفيديو عبر Mediabunny |

للتحديث لاحقًا: `npx skills add remotion-dev/skills` أو `/remotion-upgrade`.
