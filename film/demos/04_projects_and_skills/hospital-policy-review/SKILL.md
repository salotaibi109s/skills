# مراجعة سياسات وإجراءات المستشفى

مهارة قابلة لإعادة الاستخدام: كل مراجعة تبدأ من نفس المنهجية ونفس نموذج التقرير.

## المنهجية (نفّذها بالترتيب)
1. **التعريف**: استخرج عنوان السياسة، رقمها، الإصدار، تاريخ الاعتماد، تاريخ المراجعة القادمة، الجهة المالكة.
2. **التدقيق**: قيّم كل معيار في الجدول أدناه: `مستوفى` / `مستوفى جزئياً` / `غير مستوفى`، مع اقتباس قصير من النص كدليل، أو عبارة «لا يوجد نص» إن غاب.
3. **المخاطر**: صنّف كل فجوة: عالية (تمس سلامة المريض مباشرة) / متوسطة / منخفضة.
4. **التوصيات**: توصية واحدة قابلة للتنفيذ لكل فجوة، بصيغة فعل أمر.
5. **الدرجة**: مستوفى = 2، جزئي = 1، غير مستوفى = 0؛ النسبة = المجموع ÷ (2 × عدد المعايير).

## معايير التدقيق
| # | المعيار |
|---|---------|
| 1 | الغرض والنطاق محددان بوضوح |
| 2 | التعريفات للمصطلحات الأساسية |
| 3 | المسؤوليات محددة لكل دور |
| 4 | خطوات الإجراء متسلسلة وقابلة للتنفيذ |
| 5 | ضوابط سلامة المرضى ومنع الأخطاء |
| 6 | مؤشرات أداء ومتابعة الامتثال |
| 7 | التوثيق والسجلات المطلوبة |
| 8 | المراجع والمعايير المعتمدة |
| 9 | تاريخ الاعتماد ودورية المراجعة |
| 10 | التدريب والتوعية |

## قواعد
- لا تفترض وجود نص غير موجود؛ الغياب = «غير مستوفى».
- لا تقدّم استشارة طبية سريرية؛ المراجعة إجرائية وتوثيقية.
- استخدم نموذج `templates/report_template.md` حرفياً.
- اختم بسطر: «هذه مراجعة مساندة وتتطلب اعتماد لجنة السياسات».
